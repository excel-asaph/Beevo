DEPLOYMENT IMPLEMENTATION MANUAL
==============================

WARNING: This plan targets a Single-Server VPS environment (DigitalOcean, AWS EC2, Linode).
Separate cloud services like Vercel + Heroku are NOT suitable because the App requires a shared filesystem (Watchers write to Client assets).

2. INFRASTRUCTURE SETUP (VPS)
--------------------------------------------------------------------------------
Use Ubuntu 22.04 LTS with Node.js 20+.

DIRECTORY STRUCTURE (Example: /var/www/beevo/)
/var/www/beevo/
├── client/dist/           # Built React App (Static Files)
├── server/dist/           # Compiled Backend
├── server/brain/          # SQLite DB & Configs (Read/Write)
├── server/src/            # Source for Watchers (run via tsx)
├── package.json
└── ecosystem.config.js    # PM2 Configuration

--------------------------------------------------------------------------------
3. BUILD & DEPLOY SEQUENCE
--------------------------------------------------------------------------------

STEP 1: BUILD (Run Locally)
   npm install
   npm run build:client   -> Creates client/dist/
   npm run build:server   -> Creates server/dist/

STEP 2: CONFIGURE PM2 (Create 'ecosystem.config.js' in root)
   module.exports = {
     apps: [{
       name: "beevo-server",
       script: "./server/dist/index.js",
       env: {
         NODE_ENV: "production",
         PORT: 3001
       }
     }, {
       name: "beevo-watchers",
       script: "npm",
       args: "run start:watchers",
       autorestart: true
     }]
   }

STEP 3: CONFIGURE NGINX (Reverse Proxy)
   server {
       listen 80;
       server_name beevo.app;

       # 1. Serve Frontend
       location / {
           root /var/www/beevo/client/dist;
           try_files $uri $uri/ /index.html;
       }

       # 2. Proxy API
       location /api/ {
           proxy_pass http://localhost:3001;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
       }

       # 3. Serve Shared Assets (The Bridge)
       location /assets/ {
           root /var/www/beevo/client/public;
       }
   }

--------------------------------------------------------------------------------
4. INITIALIZATION
--------------------------------------------------------------------------------
On the server, run this command ONCE to set up the database and folders:
   npm run init:system

--------------------------------------------------------------------------------
5. MAINTENANCE
--------------------------------------------------------------------------------
- View Logs:    pm2 logs
- Restart App:  pm2 restart beevo-server
- Backup:       Copy the 'server/brain' folder (it contains your DB and Configs).
