Implementation Plan - Autonomous Optimization Loop & Dev Mode
Goal
Build a self-correcting, autonomous landing page engine. The system uses a JSON-Driven Architecture where the AI acts as a CMS (Content Management System), updating a configuration file that the Frontend immediately renders. This avoids server restarts and enables real-time "Watch and Fix" loops.

Phase 16: Deep Dive - Block 1 (The Hook)
Strategy: Perfect the "Hero Section" through a "Champion vs. Challenger" binary system, leveraging Gemini's Spatial Understanding (Vision) to analyze why a variation wins or loses.

1. The Strict "3-File" Asset Context
To handle the optimization loop with full context, we maintain THREE explicit states for the block assets (Video/Schema).

_benchmark (The King): The frozen, user-approved standard we must beat.
_challenger (The Current Live Test): The current iteration running on the frontend.
_candidate (The Context/History): The temporary "new try" or "previous fail" used for diffing.
Optimization Flow:

Cold Start: Create _challenger (v1). (Benchmark is empty or null).
Tracking: Frontend tracks _challenger.
Optimization Loop:
Generate _candidate (v2).
Compare _candidate metrics vs _challenger.
If Candidate Wins: _candidate overwrites _challenger.
Compare _challenger vs _benchmark.
If Challenger Wins: _challenger overwrites _benchmark (New Standard).

3. The Logic: Tracking & Adherence
A. What are we Tracking? (The Signals)
We track specific interactions to diagnose specific layers.

Component	Metric	If Score is Low...	The AI Action

2. Move text_position (CSS).
CTA Button	CTR (Clicks)	The Offer is weak or Button is invisible.	1. Rewrite cta.text (Copy).
2. Change cta.style (CSS).
B. The Immutable Constraints (Brand DNA)
The AI cannot invent styles. It must Read & Adhere to 
complete_research_latest.json
.

Colors: AI strictly picks from brandDNA.colorPalettes[selected].colors.
Example: If palette has "Neon Blue" and "Black", the cta.style must map to these.
Fonts: UI renders using brandDNA.typographyPairings[selected].fonts.
Logo: UI renders brandDNA.logoStructures[selected].
Voice: Copy (Headline/Subhead) must match brandDNA.voice.
C. The Variable "Knobs" (AI Control)
The AI only plays with:

Layout: Where the text sits (text_position).
Visuals: What happens in the video (visual_asset).
Copy: What the text says (overlay_content).
4. Safety Mechanisms (The "Hybrid Guard")
To balance AI Autonomy with Brand Consistency.

A. The Immutable Constraints (Hard Locks)
Certain attributes are LOCKED to the 
complete_research_latest.json
.

fontFamily: The AI cannot choose "Comic Sans". It must return the string "Fraunces" or "Montserrat" (from your research).
color / backgroundColor: The AI cannot choose random pink. It must return a hex code from your selected Palette (e.g., #2E5BFF, #FF6B00).
B. The Variable Attributes (AI Playground)
These are standard CSS attributes the AI can change to optimize the design:

fontSize, fontWeight, letterSpacing, lineHeight
margin, padding, gap
textShadow, boxShadow
justifyContent, alignItems, textAlign
Validation Strategy:

Zod Schema: We lock the keys (e.g., headline.styles).
Runtime Check: We verify that color is in brandColors[]. If not, we force it to the Primary Brand Color.

Phase 1: Architecture Shift (JSON-Driven Rendering)
To solve the "Deployment" and "Tracking" visibility issues, we will not generate static HTML files. Instead, we build a Generic Rendering Engine on the client.

The Deployment: "Deploying" simply means the AI updates the current_page_config.json file. The frontend detects the change (via WebSocket or Polling) and re-renders instantly.

2. The Logic: "Waterfall Optimization"
The AI optimizes top-down to ensure causality.

Stage 1: The Hook (Block 1)
Trigger: High Bounce Rate.
Fix: AI regenerates the Headline or swaps the Veo Video ID in the JSON.
Stage 2: The Story (Blocks 2-5)
Trigger: High "Scroll Velocity" (Skimming).
Fix: AI shortens text, increases contrast in Nano Banana images.
Stage 3: The Sale (Block 6)
Trigger: Low Click-Through Rate on CTA.
Fix: AI changes CTA color (CSS) or Offer Text.
